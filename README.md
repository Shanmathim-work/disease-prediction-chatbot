# 🩺 Disease Prediction Chatbot

An AI-based healthcare chatbot that predicts possible diseases based on user-entered symptoms using Machine Learning and Streamlit.

## 🚀 Features
- Predicts diseases from symptom descriptions
- Chat-style interactive UI
- Symptom selection support
- Visual probability bars
- Machine Learning model trained on symptom-disease data

## 🛠️ Technologies Used
- Python
- Scikit-learn
- Streamlit
- Pandas
- TF-IDF Vectorization
- Logistic Regression
